## מצב קיים (כדי לא לבנות פעמיים)
- `/submit` **כבר חי**: טופס הוספת מעשה — כותרת, הסבר, קטגוריה, שנה, מדיה (תמונה/יוטיוב/העלאה עד 50MB), מקור חובה (אחד) → נכנס לתור המתנה
- `/admin` **כבר חי**: מסך אישור/דחייה של הגשות
- **עבודה לא־שמורה מסשן קודם** (~540 שורות): ממשק דו־לשוני עברית/אנגלית, דילוג אוטומטי על סרטוני יוטיוב חסומים בבמה, מקור לידים מרכז־פרס. צריך בדיקה → החלטה אם לפרסם

## משימה 1 — מנגנון הוספת מעשה (להשלים את החסר)
- [ ] **בדיקת דדופ באישור**: כשתומר מאשר הגשה, הקוד בודק אם המעשה כבר קיים באתר (מזהה סרטון / כותרת דומה / מילות מפתח) → אם קיים, מראה איפה ושואל מה לעשות
- [ ] **אזהרת מדיה חסרה**: אין תמונות/סרטון בהגשה → "בטוח שאתה רוצה לפרסם בלי?"
- [ ] כמה מקורות להגשה (כרגע רק אחד) — יבוצע יחד עם משימה 4 (סכמת מקורות חדשה)
- [ ] כמה תמונות להגשה

## משימה 2 — תפאורה חדשה
- [ ] כיוון: מגניב + ממלכתי + מתאים לכל הגילאים + קל לשימוש
- [ ] להכין 2–3 כיווני עיצוב להשוואה (השראה מאתרי־על, לא "מכני/זול")
- שמורים מהעבר: navy+gold, במה גדולה במרכז, בלי נקודות ניווט

## משימה 3 — תיוגים
- [ ] דוח מצב קיים על כל התיוגים ← **רץ עכשיו**
- [ ] תיוג מדינות ספציפיות (אמריקה, ...)
- [ ] תיוג מאות שנים: התיוג נקרא "1900–2000" וכו' — פילטר לפי תקופה (מחושב אוטומטית משדה השנה)
- [ ] תיוג/פילטר יש־סרטון / אין־סרטון

## משימה 4 — מקורות (הלב של האתר)
- [ ] סריקה: כמה פריטים נשענים על ויקיפדיה בלבד ← **רץ עכשיו**
- [ ] צינור מקורות: ויקיפדיה → המקורות שהיא עצמה מצטטת → קריאת כל מקור → דירוג מהרלוונטי ביותר → שמירת ציטוט + עמוד/מיקום
- [ ] סכמה חדשה: הרבה מקורות לכל מעשה (10, 20, כמה שיש), ממוינים לפי רלוונטיות
- [ ] כלל ברזל: ויקיפדיה = מקור משני בלבד, לעולם לא יחיד
