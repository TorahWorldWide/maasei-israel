# ARCHIVED-REJECTED — הדי לאמאר

עליו דף, לצטט ממנו או לשחזר ממנו מעש.**

אתר של מעשי ישראל."*

לאמאר היה **הדף הקנוני הראשון**, אמת המידה לסוג `single-inventor` (כלל 166). אחרי
מסירת v3 נשאלה שאלה אחת — האם המכשיר נבנה אי-פעם — ויומן הידע ענה עליה לבדו: המכשיר
מעולם לא נבנה, הצי גנז את הפטנט, והמערכות שכן נפרסו פותחו עצמאית. הפירוט המלא, עם
המקורות, נמצא ב-[`docs/EXCLUDED.md`](../../../EXCLUDED.md).

**הכלל שנולד מכאן:** כלל 176 — מבחן ההשפעה הממומשת. השאלה "מה קרה בעולם בפועל בגלל
המעשה הזה?" נשאלת מהיום בתחקיר, לפני שנכתבת מילה.
