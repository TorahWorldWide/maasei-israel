# תוכנית 1 — תיוג שנים + פילטר תקופות

**מטרה:** להחליף את פילטר התקופות המעורפל הקיים בתיוג מאות מדויק, ולאפשר לסמן כמה מאות **לא רצופות** יחד.

**למה זו נקודת ההתחלה:** לכל 206 המעשים כבר יש שנה במסד (אומת 7.8.2026 — אפס חסרים). התיוג הוא חישוב טהור מהשדה הקיים, בלי שיפוט מודל וללא זחילה ברשת. עלות הטוקנים כמעט אפס, והתוצאה ודאית ובת־אימות.

## החלטת תכנון: לגזור, לא לאחסן

**אין לשמור את התיוג במסד.** השנה היא מקור האמת; תג שמור יכול להתיישן מולה. `eraOf(year)` מחושב בזמן ריצה. מכאן: **אפס מיגרציות, אפס סיכון לנתונים.** אם בעתיד נרצה תיוג שאינו נגזר מהשנה (מדינות למשל) — זה דיון אחר, לא כאן.

## שלבי ביצוע

### שלב א׳ — `src/lib/era.ts` (קובץ חדש)
```ts
export type Era = { key: string; from: number; to: number };
export function eraOf(year: number | null): Era | null;   // 1996 → {key:"1900-2000", from:1900, to:2000}
export function erasPresent(entries: Entry[]): Era[];      // רק תקופות שיש בהן מעשים, ממוינות
export function eraDisplay(era: Era): string;              // "1900–1900" ← קו מפריד ארוך, לא מקף
```
מפתח התג = `"1900-2000"` בדיוק כפי שתומר ביקש שייקרא.

### שלב ב׳ — `Feed.tsx`: רב־בחירה
1. למחוק את `getEra` המקומי ואת `ERAS`; לייבא מ-`@/lib/era`.
2. `const [eras, setEras] = useState<string[]>([])` — מערך ריק = הכל.
3. לוגיקת הסינון: `if (eras.length && !eras.includes(eraOf(e.year)?.key ?? "")) return false;`
   - **OR בין התקופות** (1400–1500 וגם 1800–1900 יחזירו את שתיהן)
   - **AND מול קטגוריה וחיפוש** — אל תשבור את ההתנהגות הקיימת
4. לחיצה על תג = toggle. כפתור "נקה" מופיע רק כשיש בחירה.
5. להציג מונה ליד כל תג (`1900–2000 · 101`) — מחושב מהמעשים לאחר סינון הקטגוריה והחיפוש, כדי שהמספר לא ישקר.

### שלב ג׳ — שיתוף בכתובת
`?era=1800-1900,2000-2100` נקרא ל-state בטעינה ונכתב בכל שינוי (`history.replaceState`, בלי לרנדר מחדש את הדף). כך פילטר ניתן לשליחה בוואטסאפ.

### שלב ד׳ — תג על המעשה עצמו
תומר ביקש שלכל מעשה יהיה התג. להוסיף תווית תקופה דיסקרטית ב-`EntryCard.tsx` וב-`DeedPageBody.tsx`, ולחיצה עליה מסננת לפי אותה תקופה. **דיסקרטית** — הוא חושש מעומס בממשק, אז טקסט קטן ליד השנה, לא "צ'יפ" צבעוני.

### שלב ה׳ — תרגום
`ERA_LABELS` ב-`i18n.ts`: המפתחות מספריים ולכן זהים ב-he/en. לוודא ש-`eraLabel` לא שובר את הקיים, ושהמספרים נשארים LTR בתוך טקסט עברי.
