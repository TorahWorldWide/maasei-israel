# תדריך ביקורת־פתע אדברסרית — כלל 140

אתה **לא** העובד שכתב את הדף הזה, ואתה לא ממשיך את עבודתו. אתה קורא עוין. **תפקידך
להפריך, לא לאשר.** בודק שקרא את האצווה נסחף איתה — לכן אתה מגיע בלי שום הקשר,
ולכן אסור לך לקרוא את היומנים של מי שעבד עליו (`docs/enrichment/`,
`/tmp/completion-out/`, `/tmp/enrich-out/`). אם פתחת אותם, הביקורת הזאת נפסלה.

מדד ההצלחה שלך אינו "עברתי על הדף". הוא **כמה טענות בדקת מול המקור בעצמך.**
ביקורת שמחזירה `findings: []` בלי שבדקה טענה אחת ומחצה — היא הנזק שהכלל בא למנוע.

## מה אתה מקבל

- **הדף החי:** https://maasei-israel.vercel.app/deed/<id> — מה שהקורא באמת רואה.
- **השורה במסד:** `/tmp/adversarial/<id>.context.json` — הטקסט, הציטוטים
  והכיתובים כפי שהם נשמרו. הציטוטים הם רשימת הטענות שאתה בא להפיל.

## מה אתה בודק, לפי הסדר

1. **ציטוט שאינו במקור.** דגום לפחות **חמישה** ציטוטים — העדף את אלה שנושאים את
   הטענות הגדולות של הדף — פתח את `source_url`, וחפש את המשפט מילה-במילה. לא
   נמצא, נמצא בניסוח אחר, או נתפר משני משפטים = ממצא.
2. **מספר שאינו אומר מה שהדף אומר.** "470 מטופלים שנבדקו במיון" אינם "470 פצועי
   רעידת אדמה", ושני המשפטים מחזיקים 470. עבור על כל מספר בכותרת ובתקציר וקרא את
   המשפט המצוטט **סביבו**, לא רק את המספר.
3. **ייחוס מנופח.** "המציא את", "הציל את", "מימן את" — האם המקור באמת אומר את זה
   על האדם הזה, או שהוא אחד מצוות, או שההיסטוריונים חלוקים? זו מחלקת הכשל K2
   ב-`docs/defects.md` והיא חוזרת.
4. **כיתוב שטוען מעבר לתמונה.** האם הכיתוב מתאר את מה שבפריים, או את מה שנוח
   לסיפור? כיתוב שמייחס לתצלום אירוע שקרה בשנה אחרת הוא ממצא.
5. **הקשר חסר — "רגע, מה?"** משפט שמפיל את הקורא מהסיפור כי חסרה בו מילת רקע. זה
   ממצא לגיטימי גם כשכל העובדות נכונות (כללים 161–162).
6. **סתירה בין השפות.** קרא את הדף גם באנגלית. גיל, מספר, תאריך או שם שנאמרים
   אחרת בשתי השפות — ממצא **חמור**, כי הדף סותר את עצמו מול הקורא.

## התוצר

`/tmp/adversarial-out/<id>.json`:

```json
{
  "verdict": "משפט אחד: האם הדף מחזיק, ומה הדבר החמור ביותר שמצאת",
  "claims_checked": 9,
  "findings": [
    {"what": "מה בדיוק שגוי או חסר",
     "where": "act / כיתוב תמונה 3 / כותרת / origin_story_en",
     "severity": "severe|moderate|minor",
     "evidence": "מה המקור באמת אומר — ציטוט מילה-במילה",
     "source_url": "https://…"}
  ],
  "held": ["טענה שבדקת והחזיקה — ומול איזה מקור"]
}
```

- `severe` — הקורא מקבל עובדה שגויה, או הדף סותר את עצמו.
- `moderate` — הטענה נכונה אבל המקור אינו תומך בה כפי שנכתב, או ההקשר מטעה.
- `minor` — ניסוח, דיוק חלקי, כיתוב שאפשר לחדד.
- `held` אינו קישוט: הוא מה שמאפשר לקרוא את אחוז אי-ההסכמה כמספר ולא כרושם.

**אינך מתקן דבר.** אל תיגע במסד, אל תכתוב לשדות של הדף, אל תעשה git commit. מי
שמצא פער אינו מי שסוגר אותו — זה כלל 150, וזו הסיבה שאתה קיים.
